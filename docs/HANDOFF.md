# Předání

**Relace:** 2026-11-20 (založení projektu, připraveno v chatu s lektorem)

## Kde jsme

- Kostra repa, pravidla (`CLAUDE.md`), plán M0–M7, přehled zdrojů (`docs/ZDROJE.md`), návrh specifikace M1.
- Žádný kód kromě prázdného balíčku a smoke testu.

## Co udělat dál

1. Vítek vytvoří `.env` s Gumroad tokenem.
2. Ověřit strukturu odpovědi `/v2/sales` jedním skutečným requestem, vzorek uložit do `data/private/`.
3. Podle vzorku vytvořit vymyšlený `data/sample/gumroad_sales.json`, upřesnit spec M1, nechat Vítka schválit.
4. Implementovat M1 (testy → kód).
